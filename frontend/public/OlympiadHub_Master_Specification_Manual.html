01 Sub-Domain Multi-Tenant Architecture & Code Routing

OlympiadHub implements a dynamic, multi-tenant sub-domain routing architecture. It allows schools and institutions to have their dedicated branded portals (e.g., dpsdelhi.olympiadhub.com, ryan.olympiadhub.com) while running on a single codebase with shared infrastructure.

💻 Sub-Domain Code Architecture & Execution

  • Context Provider Pattern: TenantContext.Provider wraps the application and supplies schoolId, brandingConfig, and allowedExams.
  • Scoped API Requests: All outbound HTTP requests automatically inject X-Tenant-Subdomain header for tenant data isolation.
  • White-Label Customization: Custom school logos on student dashboard headers, login screens, and PDF certificates.
  • Dynamic Fallback: If no sub-domain is detected (e.g. www.olympiadhub.com), platform defaults to the main public marketplace.
Sub-Domain Routing Logic & Code Flow
// Subdomain & Tenant Resolver Implementation (Code Reference)
export const resolveTenantFromHost = (hostname) => {
  const rootDomain = 'olympiadhub.com';
  if (!hostname || hostname.includes('localhost') || hostname === rootDomain) {
    return { isRoot: true, tenantSlug: null, schoolName: 'OlympiadHub Global' };
  }
  
  const parts = hostname.split('.');
  if (parts.length > 2 && parts[0] !== 'www') {
    const tenantSlug = parts[0].toLowerCase();
    return {
      isRoot: false,
      tenantSlug: tenantSlug,
      apiUrl: `https://api.olympiadhub.com/v1/tenants/${tenantSlug}`,
      portalType: 'INSTITUTIONAL_SUBDOMAIN'
    };
  }
  return { isRoot: true, tenantSlug: null };
};
02 Live AI Web Camera Proctoring & Exam Security

To ensure 100% academic integrity and prevent cheating during online national/international Olympiads, OlympiadHub incorporates an AI WebRTC Camera Proctoring System with browser security enforcement.

📹 Live Web Camera Monitoring

  • Pre-Exam WebCam Diagnostic: Forces students to grant browser camera/mic permissions before launching the test.
  • Continuous Stream Capture: High-efficiency video feed preview rendered inside a non-intrusive floating HUD.
  • Automated Periodic Snapshots: Encrypted webcam snapshots captured every 15-30 seconds and uploaded to cloud proctor storage.
  • Live Supervisor Stream: Real-time multi-grid view for exam invigilators to supervise candidates simultaneously.

🛡️ AI Face Detection & Anti-Cheating

  • Face Absence Detection: Flags when candidate leaves the camera frame for > 5 seconds.
  • Multiple Face Detection: Alerts when secondary persons or unauthorized helpers are detected in the frame.
  • Tab-Switch & Blur Listener: Detects when a student switches tabs, minimizes window, or opens search engines.
  • Full-Screen Lockout: Forces full-screen mode; prompts violation count if exited.
  • Clipboard & Shortcut Lockdown: Disables Right-Click, Copy, Paste, PrintScreen, Inspect Element, and DevTools shortcuts.
